차단 키워드

🚫 차단 키워드 목록 관리

이곳에 설정 된 키워드가 제목에 포함되면 게시글 목록에서 안보이게 됩니다.

👤 차단 닉네임 목록 관리

이곳에 설정 된 사용자는 게시글 및 댓글 목록에 보이지 않게 됩니다.
(닉네임을 변경하여도 memberId 값을 기반으로 차단하기 때문에 보이지 않습니다.)

📝 유저 메모 목록 관리

개드립 본섭에서 등록했던 사용자들의 고유 메모 리스트입니다.
등록된 메모 배지를 누르면 내용을 간편하게 즉시 수정하거나 삭제할 수 있습니다.

🖼️ 차단된 개드립콘 (단일 파일 기준)

차단된 이모티콘은 본문이나 댓글창에 보이지 않습니다.

📦 차단된 개드립콘 (패키지 그룹 기준)

해당 개드립콘 전체가 본문이나 댓글창에 보이지 않습니다.

📐 레이아웃 숨김 및 특수 필터 제어

체크된 항목의 경우 게시물 목록이나 메인에서 보이지 않게 됩니다.

🚫 차단 사용자 처리 방식

💾 데이터 백업하기

개드립콘 절약모드 혹은 색상반전 모드를 제외한 차단 대상(키워드, 사용자, 개드립콘)과 기본 설정값이 저장됩니다.

💾 데이터 복원하기

기존에 다운로드 받아둔 백업(.json) 파일을 불러와 시스템의 차단 구성과 레이아웃 비율을 원상복구합니다.
