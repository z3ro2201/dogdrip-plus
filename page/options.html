차단 키워드

🚫 차단 키워드 목록 관리

이곳에 보관된 키워드가 제목에 포함되면 타겟 게시글 인스턴스가 목록에서 통째로 소멸 처리됩니다.

👤 차단 닉네임 목록 관리

특정 어그로 작성자 또는 무분별한 댓글 도배 유저의 글과 코멘트를 감추는 전역 차단 장치입니다.

🖼️ 차단된 개드립콘 (단일 파일 기준)

본문이나 댓글창 서핑 중 콕 집어서 차단한 단 한 장의 이모티콘 파싱 정보 리스트입니다.

📦 차단된 개드립콘 (패키지 그룹 기준)

패키지 세트 전체를 통합 차단 리스트에 올려, 해당 카테고리 콘들이 전부 뜨지 않게 묶어둔 영역입니다.

📐 레이아웃 숨김 및 특수 필터 제어

체크 활성화 시 단 1프레임의 깜빡임도 없이 개드립 문서 최상단 레벨에서 레이아웃 부품들을 소멸시킵니다.

💾 데이터 백업하기

현재 스토리지의 모든 최적화 밸류와 레이아웃 커스텀 수치를 추출해 안전하게 내보냅니다. (쿠키 정보 제외)

💾 데이터 복원하기

기존에 다운로드 받아둔 백업(.json) 파일을 불러와 시스템의 차단 구성과 레이아웃 비율을 원상복구합니다.
