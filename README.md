# 🛡️ 개드립 Plus+

> **개드립(dogdrip.net)을 내 입맛대로 더 쾌적하고 깔끔하게!**
> 원치 않는 어그로 글, 무분별한 뇌절 댓글, 보기 싫은 개드립콘을 흔적 없이 완벽하게 지워주는 내 손안의 개드립 전용 클린 필터 프로그램입니다.

---

## ✨ 핵심 기능 안내

### 📥 간편 Dogdrip++ 데이터 이관 (원클릭 마이그레이션)

- **기존 사용자를 위한 원클릭 패스**: 기존에 Dogdrip++ 확장프로그램을 사용 중이셨다면 복잡한 세팅을 다시 할 필요가 없습니다. 백업 데이터 파일만 넣어주면 새로 만든 객체(Object)형 마스터 구조에 맞게 알아서 변환되어 즉시 이사가 완료됩니다.

### 🚫 눈이 편안해지는 초정밀 차단 기능

- **차단 키워드**: 보기 싫은 단어를 등록해 두면, 게시글 목록(웹진형/테이블형 모두 포함)에서 해당 글을 흔적도 없이 숨겨줍니다.
- **사용자 차단**: 커뮤니티 내의 특정 악성 유저의 게시글과 댓글을 내 화면에서 완전히 격리합니다.
- **뇌절 개드립콘 폭파**:
  - ❌ **이 콘만 차단**: 댓글창에서 보기 싫은 뇌절 짤방(개드립콘) '단 하나'만 콕 집어서 차단
  - 📦 **이 그룹 전체 차단**: 해당 개드립콘 세트(그룹) 전체를 통째로 보이지 않게 차단

### 📐 깜빡임 없는 내 맞춤형 화면 레이아웃 설정

- **화면 미니멀리즘**: 상단 공지사항, 실시간 인기글 목록, 우측 사이드바 등 시선을 분산시키는 구역들을 내 입맛대로 끄고 켤 수 있습니다.
- **클린 컴팩트 모드**: 리스트 간격을 촘촘하게 줄여 한눈에 많은 글을 볼 수 있는 고효율 모드를 지원합니다.
- **스트레스 제로 추천 아이콘**: 댓글과 목록의 추천 숫자를 부담 없는 **귀여운 아기(👶) 아이콘**으로 치환하고, 감정을 상하게 만드는 비추천 버튼을 화면에서 영구 파괴합니다.
- **대화면 와이드 확장**: 화면 넓이를 내 모니터 크기에 맞게 수치(예: `1200`, `1400`)로 직접 입력하여 넓고 시원하게 키울 수 있습니다.

### 🎬 유튜브 알고리즘 시청 기록 방어

- 개드립 본문에 첨부된 유튜브 영상을 재생해도 **내 개인 구글 계정 시청 기록에 남지 않습니다.**
- 커뮤니티에서 무심코 영상을 봤다가 내 유튜브 홈 화면이 원치 않는 알고리즘으로 오염되는 현상을 원천 차단합니다.

### 🎛️ 스마트 토글 제어반 및 상세 대시보드

- **퀵 패널창**: 브라우저 우측 상단 아이콘 클릭 한 번으로 야간 모드, 데이터 절약 모드 등을 스마트폰 토글 만지듯 간편하게 제어합니다.
- **상세 설정창 (대시보드)**: 내가 차단한 키워드와 사용자 목록을 실시간으로 검색하고, 차단 조건을 '시작하는 단어' 또는 '포함하는 단어'로 정밀하게 수정·관리할 수 있습니다.

### 💾 안전한 데이터 백업/복구 시스템

- **통합 내보내기**: 수천 개의 차단 내역(키워드/사용자/개드립콘)과 내 화면 설정값을 단 하나의 `.json` 파일로 안전하게 저장합니다.
- **원격 실시간 동기화**: 백업 파일을 불러오거나 기존 Dogdrip++ 데이터를 이관하는 즉시 현재 켜져 있는 모든 개드립 탭들이 자동으로 새로고침되어 즉각 필터가 반영됩니다.

## 🚀 3분 만에 설치하고 적용하기

1. 본 페이지 우측 상단의 **[Code] -> [Download ZIP]**을 눌러 파일 다운로드 후 압축을 풀어줍니다.
2. 크롬(Chrome) 또는 웨일, Brave 브라우저 주소창에 `chrome://extensions/`를 입력하여 설정 페이지로 이동합니다.
3. 설정 창 우측 상단의 **[개발자 모드]** 토글 스위치를 켭니다(ON).
4. 좌측 상단에 나타난 **[압축해제된 확장 프로그램을 로드합니다.]** 버튼을 클릭합니다.
5. 아까 압축을 풀었던 폴더(가장 겉 표지 폴더)를 선택하면 설치가 끝납니다!
6. 💡 **[필수 세팅]** 설치 직후 브라우저 우측 상단의 **🧩 퍼즐 조각 아이콘**을 누른 뒤, **[개드립 Plus+] 옆의 📌 고정 핀 아이콘을 파랗게 활성화**해 주세요. 그래야 언제든 아이콘을 딸깍 클릭해 빠른 차단창을 꺼낼 수 있습니다!

## ⌨️ 단축키 편의 기능 가이드

- 본섭 화면 및 상세 설정 대시보드에서 유저 차단 창이나 키워드 수정 팝업창이 활성화되었을 때, 마우스를 움직일 필요 없이 키보드의 **`ESC` (Escape)** 키를 누르면 팝업창이 즉시 부드럽게 닫힙니다.
