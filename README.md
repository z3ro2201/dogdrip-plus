# 🛡️ 개드립 Plus +

> **개드립(dogdrip.net)을 더 쾌적하고 깔끔하게!**
> 불필요한 어그로, 원치 않는 레이아웃 깜빡임, 알고리즘 오염을 한 방에 완벽 차단하는 초경량 브라우저 확장프로그램입니다.

---

## ✨ 핵심 기능 (Key Features)

### 🚫 정밀 차단 시스템 (Blocking Engine)

- **키워드 필터링**: 제목에 등록한 키워드가 포함되면 웹진형/테이블형 리스트에서 흔적도 없이 소멸시킵니다.
- **사용자 차단**: 보고싶지 않은 사용자의 게시글과 댓글을 페이지 전체에서 완전 격리합니다.
- **보고 싶지 않은 개드립콘 차단**:
  - ❌ **단일 개드립콘 차단**: 게시글/댓글에 쓰인 특정 개드립콘 단 한 하나만 차단
  - 📦 **그룹 개드립콘 차단**: 해당 개드립콘 전체를 통합 차단 리스트에 설정

### 📐 렌더링 깜빡임 제로 레이아웃 필터 (Layout Controller)

- **스위칭 레이어 구성**:
  - 공지사항 및 인기글 목록 안보기 (`.notice`, `.popular-item`)
  - 우측 인기글 사이드바 안보기 (`.clayerbox-right`)
  - 컴팩트 모드 스위칭 (`.recent_wrap`, `.favorite`)
- **추천 기능 비활성화**: 댓글 및 리스트의 추천수를 시각적으로 부담 없는 **아기(👶)아이콘**으로 치환하고 비추천 버튼을 흔적 없이 영구 파괴합니다.
- **가변 본문 넓이 수동 설정**: 팝업창이나 대시보드에 원하는 수치(예: `1200`, `1400`)를 직접 입력하여 와이드 대화면 그리드로 가변 확장할 수 있습니다.

### 🎬 유튜브 알고리즘 기록 방어 (Youtube Privacy Guard)

- 본문에 설정된 유튜브 플레이어 주소를 로딩 시점에 `youtube-nocookie.com` 도메인으로 실시간 치환합니다.
- 영상을 재생해도 **개인 구글 계정 시청 기록에 남지 않아**, 커뮤니티 이용 후 유튜브 홈 화면이 원치 않는 알고리즘으로 오염되는 현상을 원천 차단합니다.

### 🎛️ 쾌적한 개드립 이용 설정

- **개드립콘 절약모드** 및 **색상 반전모드**를 간이 설정창에서 스마트폰 토글 만지듯 다이내믹하게 끄고 켤 수 있습니다.
- **마스터 대시보드 (`options.html`)**: 원안 고유의 삼성 One UI / 머티리얼 디자인 3 타원형 알약 선택 바를 채택하여 넓은 대화면에서 정갈하게 차단 데이터 배지(Badge)들을 관리합니다.

---

## 💾 백업 및 복구 엔진 (Backup & Restore)

- **쿠키 데이터 제외 설계**: 브라우저 세션에 종속되어 오작동을 유발할 수 있는 휘발성 세팅값(절약모드, 테마 쿠키)을 백업 대상에서 안전하게 배제했습니다.
- **통합 스냅샷 내보내기**: 사용자가 등록한 수천 개의 **차단 DB 목록(키워드/닉네임/개드립콘)**과 **가변 넓이 수치**, **체크박스 활성화 상태**까지 하나의 `.json` 파일로 정밀 캡처하여 저장합니다.
- **원격 올킬 새로고침**: 설정화면에서 백업 파일을 불러오거나 설정 정보를 변경하는 즉시, **현재 켜져있는 모든 개드립 탭들을 추적해 새로고침**을 진행합니다.

